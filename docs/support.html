الدعم الفني وحلول التشغيل

هذه الصفحة تجمع أهم الحلول العملية لتشغيل AM-Trading على Windows، ومعالجة مشاكل التثبيت، القفل، تحميل النسخة، وفتح الموقع.

فهرس الدعم

متطلبات التشغيل تحميل نسخة Windows حل qgeoview.dll إعداد أول تشغيل إعادة ضبط PIN الموقع لا يفتح أوامر تشخيص

1. متطلبات التشغيل

قبل تشغيل AM-Trading تأكد من توفر المتطلبات الأساسية التالية:

  • Windows 10 أو Windows 11.
  • اتصال إنترنت عند أول تشغيل.
  • مساحة كافية لتثبيت بيئة Python والمكتبات التحليلية.
  • تشغيل البرنامج كمستخدم عادي، وليس بالضرورة كمسؤول.
  • عدم حذف ملفات DLL الموجودة بجانب FinceptTerminal.exe.

2. تحميل نسخة Windows من GitHub Actions

عند بناء نسخة Windows من GitHub Actions، يتم إنتاج ملف Artifact باسم قريب من: 

AM-Trading-Windows-x64.zip

طريقة التحميل:

  1. افتح مستودع المشروع في GitHub.
  2. ادخل إلى تبويب Actions.
  3. افتح آخر Build ناجح.
  4. انزل إلى قسم Artifacts.
  5. حمّل AM-Trading-Windows-x64.
  6. فك الضغط في مجلد مستقل مثل F:\Trading\AM-Trading-Windows-x64.

3. حل مشكلة qgeoview.dll

إذا ظهرت رسالة مثل:

The code execution cannot proceed because qgeoview.dll was not found.

فهذا يعني أن حزمة Windows ناقصة مكتبة تشغيل مهمة. الحل:

  • تأكد أن الملف qgeoview.dll موجود بجانب FinceptTerminal.exe.
  • لا تضع DLL داخل System32.
  • لا تحمّل DLL من مواقع عشوائية.
  • أعد بناء البرنامج من GitHub Actions بعد التأكد من خطوة packaging.

بعد الإصلاح، يجب أن يحتوي مجلد التشغيل على:

FinceptTerminal.exe
qgeoview.dll
Qt6Core.dll
Qt6Gui.dll
Qt6Widgets.dll
Qt6Charts.dll

4. First-Time Setup بطيء أو متوقف

عند أول تشغيل يقوم البرنامج بتثبيت Python Runtime، وإنشاء بيئات معزولة، وتثبيت مكتبات التداول والتحليل. هذه الخطوة قد تكون بطيئة.

إذا بقي على Installing لفترة طويلة، افحص العمليات:

Get-Process python,pip,FinceptTerminal -ErrorAction SilentlyContinue |
  Select-Object Name,CPU,WorkingSet,StartTime

وافحص ملفات السجل:

Get-ChildItem "$env:LOCALAPPDATA\com.fincept.terminal" -Recurse -Include *.log,*.txt -ErrorAction SilentlyContinue |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 10 FullName,LastWriteTime,Length

5. إعادة ضبط PIN

إذا نسيت PIN أو ظهر قفل مؤقت بسبب محاولات خاطئة، يمكن تصفير بيانات PIN من Windows Credential Manager.

أغلق البرنامج أولًا:

Get-Process FinceptTerminal -ErrorAction SilentlyContinue | Stop-Process -Force

ثم احذف مفاتيح PIN فقط:

cmdkey /delete:FinceptTerminal/pin_hash
cmdkey /delete:FinceptTerminal/pin_salt
cmdkey /delete:FinceptTerminal/pin_failed_attempts
cmdkey /delete:FinceptTerminal/pin_lockout_until
cmdkey /delete:FinceptTerminal/pin_lockout_stamp

تحقق أن المتبقي فقط هو api_key:

cmdkey /list | findstr /i FinceptTerminal

إذا ظهر فقط:

Target: LegacyGeneric:target=FinceptTerminal/api_key

فهذا جيد. شغّل البرنامج وسيطلب إنشاء PIN جديد.

6. موقع GitHub Pages لا يفتح على الكمبيوتر

إذا كان الموقع يعمل على الجوال مع VPN ولا يعمل على الكمبيوتر، فالمشكلة غالبًا من الشبكة أو DNS، وليست من الموقع.

اختبر الاتصال:

nslookup sanaa-wq.github.io
curl.exe -I "https://sanaa-wq.github.io/AM-Trading/"
Test-NetConnection sanaa-wq.github.io -Port 443

إذا فشل الاتصال على المنفذ 443، جرّب:

  • تشغيل VPN على الكمبيوتر.
  • استخدام Cloudflare WARP.
  • تغيير DNS إلى 1.1.1.1 و 8.8.8.8.
  • تفعيل Secure DNS داخل Chrome.

تغيير DNS للواجهات المتصلة:

Get-NetAdapter | Where-Object {$_.Status -eq "Up"} | ForEach-Object {
    Set-DnsClientServerAddress -InterfaceAlias $_.Name -ServerAddresses "1.1.1.1","8.8.8.8"
}

ipconfig /flushdns
Clear-DnsClientCache

7. أوامر تشخيص مفيدة

فحص وجود البرنامج

Test-Path "F:\Trading\AM-Trading-Windows-x64\FinceptTerminal.exe"

تشغيل البرنامج من المسار الصحيح

cd F:\Trading\AM-Trading-Windows-x64
.\FinceptTerminal.exe

فحص ملفات التطبيق المحلية

Get-ChildItem "$env:LOCALAPPDATA\com.fincept.terminal" -Recurse -Force -ErrorAction SilentlyContinue |
  Select-Object FullName

فحص GitHub Pages

curl.exe -I "https://sanaa-wq.github.io/AM-Trading/"

لم تجد الحل؟

افتح بلاغًا في GitHub Issues، وضع صورة الخطأ، وناتج PowerShell، واسم نسخة Windows التي تستخدمها.
